# Netflix-Clone-SwiftUI
**Description:**
A sleek, Netflix-inspired streaming app clone entirely in **SwiftUI**, featuring  **dynamic-themed design** to emulate the immersive Netflix aesthetic. The application fetches content **dynamically** from API, ensuring real-time movie and show data without manual updates. By incorporating the **MVVM** (Model-View-ViewModel) architecture, the project achieves a clear separation of concerns, enhanced maintainability, and straightforward scalability for adding new features.

**Key Features:**
**Pure SwiftUI:** Leveraged the power of SwiftUI to build a responsive, adaptive interface for iPhone and iPad devices.

**Dynamic Content:** Integrated with IMDB API to fetch real-time data for popular, trending, and upcoming titles.

**MVVM Architecture:** Implemented a clear separation between data (Model), business logic (ViewModel), and UI (View), improving code maintainability and testability.

**Dark-Themed Interface:** Focused on a sleek, all-black design for an immersive viewing experience, mirroring the Netflix brand aesthetic.

**Scalable Design:** Built to easily extend functionality—such as adding search, user profiles, or watchlists—by simply incorporating new view models and views.

**Technologies & Tools:**
SwiftUI for the UI layer and declarative design.
Combine (or async/await if preferred) for handling asynchronous API calls in Swift.
MVVM as the architectural pattern to streamline data flow.
Xcode as the primary development environment.
